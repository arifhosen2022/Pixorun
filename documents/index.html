Purpose and ecosystem

OVERVIEW

What is PIXORUN?

PIXORUN is a reputation-focused token launchpad project being developed for Robinhood Chain. Its goal is to make token launches more thoughtful by considering wallet and social reputation.

Project overview
ECOSYSTEM

Core Products

The PIXORUN ecosystem is planned around the Genesis Pass NFT, a reputation-aware token launchpad and community participation through the GTD campaign.

Initial Token Model

The current initial Beta plan is a fixed-supply ERC-20 token model, with a limit of one token per wallet. This describes the planned test design, not a live deployment.

GTD CAMPAIGN RULES

Points and participation

TASK POINTS

How Points Are Earned

Follow @pixorun: 0.2 points. Like the campaign post: 0.3. Retweet it: 0.3. Publish an original post mentioning @pixorun: 0.5. Completing all four tasks earns 1.3 points.

VIEW CAMPAIGN ↗
REFERRALS

Referral Points

A successful referral is counted only after the invited participant completes all campaign tasks and submits. The referrer receives 1.0 point and the new participant receives 0.5 point. A maximum of 20 successful referrals can earn points per referrer.

Campaign rules
PARTICIPATION

Submission & Eligibility

Participants submit their X username, campaign post URL and EVM wallet. There is no minimum X follower requirement. Completing tasks or earning points does not guarantee eligibility or any token allocation.
