# PIXORUN

PIXORUN is a testnet-first token launchpad concept being developed for Robinhood Chain Testnet.

## Website

The initial responsive landing page is served from `index.html`.

## Current status

- Responsive PIXORUN landing page
- Genesis Pass collection overview (222 supply)
- Private beta and Sprint One information
- Robinhood Chain Testnet information (chain ID 46630)

## Important

This repository currently contains the website frontend only. Wallet connection, on-chain Genesis Pass verification, token deployment, liquidity, and staking are not live features yet. Do not treat the landing page as a live launchpad.

- Network: Robinhood Chain Testnet
- Chain ID: 46630
