Launchpad Documentation

How PIXORUN token launches are designed to work on Robinhood Chain.

01 · Token model

Each token is planned with a fixed 10,000,000 supply. 8,000,000 tokens (80%) are allocated to the bonding curve and 2,000,000 (20%) to the treasury.

02 · Linear bonding curve

Users will be able to buy and sell while the curve is open. The target is 0.1 Testnet ETH net reserve. Buys increase the reserve and progress; sells reduce both. Progress is based on the live contract reserve.

03 · Completion

At 100% of the 0.1 ETH target, the curve permanently closes. DEX graduation is a separate phase and will only be enabled after the DEX, router, liquidity and LP custody model are selected and tested.

04 · Network

  • Network: Robinhood Chain Testnet
  • Chain ID: 46630 (0xb626)
  • Native currency: ETH
  • RPC: https://rpc.testnet.chain.robinhood.com
  • Explorer: https://explorer.testnet.chain.robinhood.com
